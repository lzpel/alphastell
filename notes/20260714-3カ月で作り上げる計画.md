# 3カ月で作り上げる計画

前提: 平日夜+週末の個人開発。ソルバーは書かず配管に徹する。各月末に「動くもの」を必ず残す。並行して Proxima Fusion (Computational Physicist) へ coverletter.tex で応募する — 応募時点で見せられるのは cadrum + 本リポジトリの設計文書とモックプレプリント。

## 1ヶ月目: ジオメトリと検証環境 (7/14–8/10)

- **W1**: alphastell-core から vmec.rs を移植(NetCDF3 リーダー・フーリエ評価・スプライン放射補間・解析 θ/φ 導関数)。6層シェル系 API は持ち込まない。wout.nc で表面点群が出ることを確認。※検証フィクスチャは alphastell 由来の nfp=4・R=11.08 m の炉級 4 周期配位(**W7-X ではない**; W7-X は nfp=5・R≈5.5 m)。幾何カーネルは配位を選ばないので W1 はこれで足りる。実際の配位比較は W9 で行う
- **W2**: 流路生成 v0 — 2枚のオフセット面の間をポロイダル/トロイダル分割した直方ダクト列。cadrum の Solid::bspline + boolean で watertight STEP(ソリッド色=材料タグ)出力
- **W3**: polyMesh 直接出力 — パラメトリック座標 (u,v,offset) から壁面直交の傾斜付き構造 hex 格子。OpenFOAM の checkMesh が通ること
- **W4**: epotFoam 環境構築(Docker)。Hartmann ケースを流し解析解と比較。**マイルストーン: fig02 が実データになる**

## 2ヶ月目: 物理の2本柱 (8/11–9/7)

- **W5**: Shercliff / Hunt ベンチマーク完了、誤差表を README と paper の Table 1 に反映(モック注記削除)**応募送信もこの週に必ず行う(心理的最難関)**
- **W6**: 相関式 MHD 圧損ネットワーク — 区間 dp/dx(Miyazaki 型壁伝導度相関)+ 曲がり/マニホールド損失係数、B(r) の区間写像。epotFoam の代表ダクトと突き合わせ
- **W7**: OpenMC 経路 — STEP → DAGMC 変換、PbLi 組成で TBR が出るところまで(ParaStell のワークフローを参考に)
- **W8**: 1セクタ通し実行: wout.nc → 流路 → Δp + TBR。**マイルストーン: 判定スカラー3つが1コマンドで出る**

## 3ヶ月目: 論文と露出 (9/8–10/5)

- **W9**: 1セクタ圧損マップ(fig01 実データ化)。W7-X 系 vs LHD 系の比較実行
- **W10**: 設計スキャン(流路本数・アスペクト比・ブリーダー厚・FCI 伝導度)→ TBR–圧損 Pareto(fig03 実データ化)
- **W11**: paper.tex の MOCK 注記全削除、書誌事項の原典照合(refs.bib の TODO)、図の仕上げ。知人・コミュニティに素読み依頼
- **W12**: arXiv 投稿 + Fusion Engineering and Design に submit(「submitted to FED」を README に記載)。parastell に小規模 PR(バグ修正 or マテリアルタグ)を送り UW-Madison に認知を作る。ISFNT/Stellarator ワークショップのライトニングトーク応募

## 撤退基準・リスク

- W3 の polyMesh 直接生成が2週間超で難航したら、暫定的に STEP → Gmsh 経由に切り替えて先へ進む(Hartmann 層の格子品質は落ちるが検証は Hartmann/Shercliff の単純形状なので成立する)
- OpenMC/DAGMC の環境構築が重い場合、TBR は W8 時点では均一組成の簡易モデルで代替し、W10 で本計算に戻す
- 就活は成果完成を待たない: 応募→面接プロセス(1〜2ヶ月)と開発が並走する前提。面接時点で「先月より進んでいる」ことが最良のシグナル
