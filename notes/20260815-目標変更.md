## 変更点3: Research Question: 磁石が核発熱から保護されているか？

TBR単独では設計空間を切れない。ステラレーターではTBRより先に磁石遮蔽が破れる。Häußler・Fischer の HELIAS 中性子工学解析の結論:

> 現行の HELIAS 設計は、調査した領域で DEMO 向けに規定された遮蔽限界を満たせない。主因はステラレーターで利用可能な空間が限られていることであり、ブランケットと遮蔽の設計改善で克服されるべき。

### 出す量は3つに絞る

同じメッシュタリー1組から取れるものだけにする。線量・dpa・He生成は落とす（応答関数や燃焼計算が要って工数が跳ねる）。

| 量 | 意味 | 限界値 |
|---|---|---|
| ピーク核発熱密度 | 局所制約 | DEMO TFC 目標 450 W/m³ |
| 全体核発熱 | 冷凍機電力→再循環電力→正味電気出力 | — |
| ピーク高速中性子フルエンス (E>0.1 MeV) | 磁石寿命 | Nb₃Sn 10²² n/m² / REBCO 3×10²² n/m² |

フルエンスは `flux` スコアにエネルギーフィルタを足すだけでタダ。**これを外すとLTS/HTSの話が丸ごと死ぬ**（差はフルエンス限界に出るのであって発熱限界には出ない）。発熱は運転中の安定性、フルエンスは寿命で別の問い。

```python
mesh_filter = openmc.MeshFilter(mesh)          # コイル周りに限定した RegularMesh
cell_filter = openmc.CellFilter(magnet_cells)
t1.filters = [mesh_filter, cell_filter]; t1.scores = ["heating"]
t2.filters = [mesh_filter, cell_filter, openmc.EnergyFilter([0.1e6, 20.0e6])]; t2.scores = ["flux"]
```

単位換算: `W/m³ = (eV/src) × S × 1.602e-19 / V_voxel`、`S [n/s] = P_fus / (17.6 MeV × 1.602e-13)`（2.7 GW なら S ≈ 9.6e20 n/s）

### 真の工数はタリーではなくこの2つ

- **光子輸送を ON にする**（`settings.photon_transport = True`）。厚い遮蔽の裏では発熱の主成分は捕獲二次ガンマ。`heating-local` だと遮蔽背面で生まれて磁石に飛び込むガンマを取り逃がし、大幅に過小評価する
- **weight window が必須**（`WeightWindowGenerator`、MAGIC法）。磁石位置の中性子束は第一壁の 10⁻⁵〜10⁻⁶ でアナログMCでは収束しない

TBRは 10⁶〜10⁷ 粒子で誤差1%以下（数分）。磁石ピーク発熱は 10⁸〜10⁹ 粒子（数時間）。**「10m級だから重い」のではなく「遮蔽の裏側を見るから重い」**。体系の大きさ自体はMCではほぼコストにならない。

### 定式化: 局所制約と大域制約の非対称性を使う

- **磁石制約は局所的**: コイルのある点に届く中性子はほぼその点の直前の径方向ビルドを通る → 実質1Dの減衰問題、`t_shield(φ,θ)` だけで決まると近似できる
- **TBRは大域的**: 3D厚み分布全体の汎関数、薄い所を厚い所で補える

手順:

1. 1D応答ライブラリを作る（平板で `(t_breeder, t_shield)` を振り、局所の減衰率と局所トリチウム生成を表にする）
2. 各 (φ,θ) で `t_shield` を磁石制約を満たす最小値に取り、残りを breeder に回す: `t_breeder(φ,θ) = Δ(φ,θ) − t_shield_min`
3. 中性子壁負荷で重み付けして積分 → 大域TBR、`TBR ≥ 1.1` を判定
4. 満たさなければ Δ 全体をスケールし、条件を満たす最小サイズ `Δ_min` を求める
5. 最後に数ケースだけ3D完全計算で 1〜3 の近似を検証

**Δ(φ,θ) は導出量ではなく設計変数**。コイル形状はプラズマ境界だけからは決まらず、コイル最適化（REGCOIL / FOCUS / simsopt）の出力。VMEC の wout にコイルは入っていない。**コイル形状データが確保できるかがプロジェクト全体の分岐点なので最初に確認する。**

### 図は3枚

1. **(t_breeder, t_shield) 平面** = 1点 (φ,θ) の局所ダイアグラム、または1D応答ライブラリの可視化。磁石制約曲線と局所トリチウム生成の等高線を描き、`t_b + t_s = Δ` の斜線を機械各所の Δ の値ぶん重ねる。一様厚みの仮定は不要
2. **Δ(φ,θ) マップ上の「解なし」領域** = 手順2で `Δ < t_shield_min` になる場所。al_05 の可視化基盤が使える
3. **必要最小 Δ_min** = 手順4の出力。文献の通説は 1.5〜2 m。装置サイズの下限＝コストの下限

### 売り: HTS で判定基準が変わる

LTS = 低温超伝導（Nb₃Sn, 4.2 K）、HTS = 高温超伝導（REBCO テープ, 20 K）。ARIES-CS も ParaStell も HELIAS も **LTS 前提**。Proxima は **HTS**。

REBCO のフルエンス許容は Nb₃Sn の約3倍（1.5〜2×10²² m⁻² まではピン止め中心が増えて Jc がむしろ上がる）。遮蔽の減衰は指数的なので、許容3倍 → 必要遮蔽厚が 10 cm 程度薄くて済む（減衰長10cmとして ln(3)×10 ≈ 11 cm）。Δ が窮屈なステラレーターではこの十数cmが解の有無を分けうる。

> **LTS 基準では解が存在しない Δ でも、HTS 基準なら解がある。その差分をブランケットに回して TBR 1.07 → 1.1+ の余裕が生まれるか？**

つまり Häußler らの否定的結論（HELIAS は遮蔽限界を満たせない）を Proxima の技術選択が覆すか、を定量化する問いになる。

**留保を必ず付ける**: REBCO の照射損傷は研究途上で、20 K 運転では損傷の焼きなましが効かず室温照射データより厳しい可能性がある。**フルエンス限界を固定値でなく入力パラメータにし、1〜3×10²² n/m² で振ったときの実現可能領域の感度を出す**。「限界値がどこまで厳しくなったら解が消えるか」を答えられることが、この不確かさの中で一番価値のある出力。

## 計算設定の目安

MC計算に固有の空間解像度はない。「解像度」は独立した3か所に現れる。

| 項目 | 設定 | 理由 |
|---|---|---|
| ファセット許容差 | 弦 1 mm / 角度 5° | 三角形数 10⁵〜10⁶ なら実用範囲。**ボトルネックは解像度でなく watertight 性**（10m機械に5mm第一壁＝アスペクト比 1:20000 で重なり・隙間が出る） |
| モデル範囲 | 1フィールドピリオドの半分、反射境界 | nfp=5 なら 1/10。ポート・保守開口を入れた瞬間に使えなくなるので二段構え |
| ギャップ | 実寸で明示モデル化 | 空隙は mfp 無限大。2cmの隙間でも直進ストリーミングで磁石に届く。**ここだけは省略不可** |
| TBR | セルタリー、メッシュなし、10⁷ 粒子 | 解像度の問題自体が発生しない |
| 磁石メッシュ | コイル周りに限定、5 cm ボクセル | 巻線パック断面 30cm なら 6×6。1cm全域メッシュは 8.1×10⁹ ボクセル = 260 GB で不可能 |
| 磁石タリー | weight window + 光子輸送 ON、10⁸〜10⁹ 粒子 | |

物理が要求する解像度の目安は平均自由行程（14 MeV）: PbLi 約7cm、鋼 約4.5cm、W 約3cm、遮蔽体の減衰長 約7〜10cm。**中性子は数cm以下の構造をほとんど見ない**のでサブmmのCADディテールは無意味。ただしギャップは例外。

3次元でボクセル辺を半分にすると1ボクセルあたりのスコアが1/8になるので、同じ誤差には粒子数8倍が要る。解像度を上げる代償は指数的。

Martelli et al. (2017) の豪華なCADは**ツールの出力ではなく専任設計チームの成果物**。著者の Di Gironimo / Tarallo / Mozzillo はナポリ大 Federico II / CREATE の CAD 統合専門チーム。6機関×数人年。

ワークフロー: PROCESS（径方向ビルド）→ **CATIA V5 で 11.25° セグメントを人が作図** → **Ansys SpaceClaim で中性子計算用に手作業 de-featuring**（週〜月かかる有名なボトルネック）→ **SuperMC の CAD-to-MCNP 変換**（冷却配管など繰り返し構造は MCNP 側で universe/lattice として直接記述するハイブリッド方式）→ MCNP / ANSYS / OpenFOAM(MHD)

## 実装計画

Martelli 論文の価値は **WCLL breeding unit の内部構造が公開文献として確定していること**。発明する必要がない。

1. **WCLL breeding unit をパラメトリック部品として cadrum/OCCT で実装** — FW の角型冷却チャンネル、増殖ゾーン内の二重管、breeding unit を仕切る補強板/バッフル、背面支持構造。寸法は論文から取る
2. **磁気面に沿って配置・インスタンス化** — ここが本当の技術的難所。二重曲率かつ非軸対称な面の上では同じユニットセルが歪みなくタイルできない。ユニット寸法をどう (φ,θ) 依存に変形させるか、どこで分割するかが研究課題そのもので、しかも純粋に幾何の問題＝得意分野
3. **均質版と不均質版で TBR を比較** — 均質版は ParaStell で作る。比較の片側が公表ツール由来になって信頼性が上がり、「既存研究を把握している」証明にもなる。**ParaStell を敵にせず使う**
4. 磁石制約（変更点3）を重ねる

順番としては不均質ΔTBRを先に小さく確実に閉じ、その上に磁石制約を重ねる。磁石形状の入力が確保できるかが分岐点なので先に確認する。

## MHD についての整理

「WCLL では MHD 不要」は誤り。問題の種類が変わる。

- **DCLL の MHD** = 圧損。PbLi が冷却材で高速に流れ、B に直交する流れのポンプ動力が設計を殺す。FCI（SiC）はその対策
- **WCLL の MHD** = 混合対流と熱・トリチウム輸送。PbLi は増殖材で流速が遅い（mm/s級）ぶん浮力駆動の自然対流が支配的になり、それを磁場が抑制する。breeding unit 内の温度分布・停滞域・トリチウム輸送が決まる。Sapienza グループ（Tassone, Caruso, Giannetti）が OpenFOAM でやっているのがこれ

圧損最適化としての流路方向の主張は弱くなるが、MHD 自体は生きている。ただし混合対流は本格的CFDなので「流体計算以外で攻める」方針は変わらず妥当。
