# nc から中性子輸送まで — 自分用の教科書

`wout.nc` を「磁場ファイル」だと誤解していた自分に向けた覚書。中性子輸送(OpenMC)が
このプロジェクトのどこに、なぜ、どう入るのかを、実際に動く `sandbox-openmc/model.py` と
行単位で対応させながら整理する。

---

## 1. VMEC 平衡 `wout.nc` は「磁場」と「磁気面形状」の両方を持つ

`wout.nc` は VMEC が解いた磁気流体力学平衡の出力で、中身はフーリエ係数の塊である。
これを「磁場ファイル」と呼ぶのは**半分しか合っていない**。`wout.nc` が持つのは:

- **磁気面の形状** — 各磁気面(フラックス面 `s` でラベルされる入れ子のドーナツ)の
  3次元形状を、円筒座標 `(R, Z)` のフーリエ級数
  `R(s,θ,φ) = Σ R_mn(s) cos(mθ − nφ)`、`Z(s,θ,φ) = Σ Z_mn(s) sin(mθ − nφ)` として持つ。
- **磁場** — 各面上の磁場の強さ・向き(`B^u, B^v`, `|B|` のフーリエ係数など)。

つまり「形状」と「磁場」は**別々の量として同居**している。プラズマ境界(最外殻の
磁気面 `s=1`)の形状を取り出せば、そこにブランケットを貼る土台になる。alphastell の
フーリエ評価カーネルが移植元(→ [[全体構成]])。

**ポイント**: `wout.nc` から中性子輸送に渡すのは**形状のほう**であって、磁場ではない。
なぜかは次節。

---

## 2. 中性子は磁場を受けない → 輸送に要るのは「形状」と「材料」だけ

中性子は電荷を持たない。したがって Lorentz 力 `qv×B` がゼロで、**磁場の中でも
まっすぐ進む**。液体金属(荷電を運ぶ導体)が磁場から力を受けて圧損を生む MHD 側とは、
ここが決定的に違う。

中性子輸送方程式(定常・線形ボルツマン方程式)にも磁場 `B` は現れない:

```
Ω·∇ψ + Σt ψ = ∫∫ Σs(Ω'→Ω, E'→E) ψ dΩ'dE' + S
```

未知数は角中性子束 `ψ(r, Ω, E)`。式に入るのは **`Σt`(全断面積 = 材料)** と、
`∇`・幾何境界(= **形状**)だけ。だから中性子計算に渡すべきは:

| 要る | 要らない |
|---|---|
| 流路・ブリーダー・壁の**形状** | 磁場 `B` |
| 各領域の**材料**(組成・密度 → 断面積) | 流速・圧力 |

`wout.nc` の磁場成分は MHD 圧損計算(相関式ネットワーク・epotFoam)が食う。中性子側は
形状だけ食う。**同じ nc から2つの経路が分岐する**、というのがパイプラインの骨格
(→ ルート README のパイプライン図)。

---

## 3. nc → CAD → DAGMC → OpenMC の二段構え

中性子輸送に要るのは形状だが、OpenMC に形状を渡す道は2通りあり、本プロジェクトは
両方を**二段構え**で使う。

### 段1: CSG(構成立体幾何)— CAD 不要、解析解で検証できる

球・円柱・平面などの一次曲面を論理演算(和・積・補)で組む方式。OpenMC が
ネイティブに持つ。**CAD カーネルもメッシュも要らない**。形が単純な代わり、
解析解と突き合わせられる。

→ これが `sandbox-openmc/`。`model.py` は
`openmc.Sphere(r=R, boundary_type="vacuum")` 1個でリチウム球を作り(CSG のみ)、
未衝突中性子束の厳密解 `φ(r)=S·exp(−Σt·r)/(4πr²)` と比較して**輸送の土台を検証**する。
Hartmann 流で epotFoam を検証したのと同じ「解析解の錨」。

### 段2: DAGMC — CAD 由来の複雑形状を三角形メッシュで

ステラレータのねじれた流路は CSG では書けない。そこで cadrum が
**材料で色付けした STEP(B-rep ソリッド)** を出力し(ソリッドの色 = 材料タグ)、
それを **DAGMC**(Direct Accelerated Geometry Monte Carlo)が三角形ファセット
(`.h5m`)に変換して OpenMC に食わせる。ParaStell のワークフローと同じ路線。

→ これが W7 以降の本番。段1 で輸送が正しいと確かめてから、重い CAD/DAGMC 依存に進む。
`sandbox-openmc` の検証は、その本番の geometry を差し替えても輸送エンジンは同じ、という
安心の土台になる。

**docker_openmc の要否**: 標準 `openmc/openmc` イメージが DAGMC 対応なら、段2 でも
自前イメージは要らない(断面積は実行時マウント)。`make env` でリンクを実測して決める
(→ `sandbox-openmc/README.md` の設計判断表)。

## 4. モンテカルロ・断面積・タリー・TBR

`model.py` が実際に何をしているかを、中性子輸送の4つの基礎概念に対応させる。

### モンテカルロ

個々の中性子の一生(線源で生まれ → 飛んで → 衝突 or 漏洩 → 消滅)を乱数で
何十万回も追跡し、統計平均として束・反応率を出す。飛行距離は `−ln(ξ)/Σt` で
標本化(`ξ` は一様乱数)されるので、`Σt` が大きい = よく衝突する = 平均自由行程
`1/Σt` が短い。決定論(epotFoam)と違い**結果に統計誤差 σ が付く** → 検証の合格判定も
「相対誤差 < 閾値」だけでなく「偏差が nσ 以内」を併用する(`compare_attenuation.py`)。

- `model.py`: `settings.run_mode = "fixed source"`(炉の臨界計算ではなく固定線源)
- `settings.particles`, `settings.batches` がヒストリ数(統計量)

### 断面積(cross section)

材料の「中性子との反応しやすさ」。核種 `i` ごとに反応 `x` の微視断面積
`σ_{x,i}(E)`(単位: barn = 10⁻²⁴ cm²)がエネルギー `E` の関数として与えられ、
巨視断面積 `Σ_x = Σ_i N_i σ_{x,i}`(`N_i` は原子数密度)が単位長さあたりの反応確率。
数 GB の評価済みライブラリ(ENDF/B-VIII.0 など)を実行時に読む。

- `build_xs.py`: 検証は Li6/Li7 の2核種だけの軽量ライブラリで足りる
  (`LIB=full` で ENDF フルに切替 → 本番の PbLi+構造材はこちら)
- `model.py` の `macroscopic_total()`: 解析解が使う `Σt(14.1 MeV)` を
  **数値解と同じライブラリ**から読む(データではなく輸送を検証しているため)

### タリー(tally)

「何を数えるか」の指定。フィルタ(場所・エネルギー・角度・衝突回数…)× スコア
(flux, 反応率…)で定義する。

- `model.py` の未衝突束: `CellFilter`(球シェル)× `CollisionFilter(bins=[0])`
  (衝突回数 0 = 未衝突)× **線源エネルギー窓** × `scores=["flux"]`
- 衝突回数フィルタだけだと落とし穴がある: 14.1 MeV では `⁷Li(n,2n)` が二次中性子を
  生み、それが**新粒子として衝突回数 0 から始まる**ため未衝突束に混入し、外側シェルほど
  過大評価される(実測 ~7%)。未衝突の源中性子は厳密に 14.1 MeV のまま・二次中性子は
  7 MeV 以下なので、線源エネルギー ±0.1% の `EnergyFilter` を併用して除く。この一手で
  厳密解と 0.1% 台で一致する
- flux スコアは飛跡長推定で**体積積分束**を返すので、シェル体積で割って平均束にする

### TBR(トリチウム増殖比)

三重水素の生成率。DT 核融合の 14.1 MeV 中性子がリチウムに吸収されて T を生む:

- `⁶Li(n,t)⁴He`(+4.78 MeV、低速中性子で大)
- `⁷Li(n,n't)⁴He`(−2.47 MeV のしきい反応、14 MeV 近傍で効く)
- 中性子増倍材(Pb, Be)の `(n,2n)` で中性子を増やしてから食わせると TBR が上がる
  → 本番の PbLi は Pb がこの役

- `model.py` の TBR タリー: `scores=["(n,Xt)"]`(Li6(n,t)+Li7(n,n't) を一括集計)
- ただし純リチウム球という非現実な体系の**参考値**。実機 TBR は PbLi 組成・
  現実的な壁厚・DAGMC 幾何の下で W7 以降に本計算する

## 5. まとめ(一枚図)

```
wout.nc (VMEC 平衡)
  ├─ 磁場   ─────────────▶ MHD 圧損 (相関式 / epotFoam)   ← 中性子は使わない
  └─ 磁気面形状
        └─▶ 流路 CAD ─▶ 色付き STEP ─▶ DAGMC (.h5m) ─▶ OpenMC ─▶ TBR
                                    (段2: 本番, W7〜)
        （検証は段1: CSG 球 + 点線源, CAD なし, 解析解 φ=S·e^{−Σt·r}/4πr²）
                                    → sandbox-openmc/model.py
```

中性子側で覚えることは1行に圧縮できる:
**中性子は磁場を無視するので、輸送に渡すのは形状と材料だけ。まず CSG + 解析解で
エンジンを検証し(sandbox-openmc)、次に CAD→DAGMC で本番形状に載せる。**
