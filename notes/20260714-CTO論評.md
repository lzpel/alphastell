# CTO論評

2026-07-14、alphastell の戦略ノート(20260421-戦略-液体金属流路OSS化とarxiv投稿)を「Proxima Fusion 等の CTO が採用候補者のプロジェクトとして見たら」という設定で論評した記録。本リポジトリの製品定義はこの論評から出た。

## ① 製品は「可視化」ではなく「成立性判定スカラー3つ」

wout.nc から液体金属のきれいな 3D 可視化を出すツールは GitHub スターは稼げてもデモ止まり。CTO が身を乗り出す出力は:

1. **TBR** ≥ 1.1〜1.15 で燃料サイクルが閉じるか
2. **MHD 総圧損 → ポンプ動力の対核融合出力比**(数%を超えたら設計は死ぬ)
3. **最高壁温度/構造材界面温度**(材料寿命・腐食限界)

つまり「この磁場配位・この流路トポロジーで成立するか Yes/No を分単位で返す判定機」が製品。設計会議でそのまま使えるのは TBR–圧損の Pareto フロント1枚。可視化は判定を信じさせる営業資料。

## ② フル 3D MHD CFD は罠。相関式ネットワークが主力

epotFoam で現実的なのは Ha≈10³、実機は Ha≈10⁴(Hartmann 層解像に 10⁸ セル級)。ヒーロー CFD 1本より、**相関式 1D ダクト網で数分で判定を返す設計スキャンツール**の方が産業価値が高い(設計チームは1日に何十案も回したい)。フル CFD は Hartmann/Hunt/Shercliff ベンチマークと代表ダクトの「検証の錨」に限定する。この二層構成が Ha 制限への査読批判の回答にもなる。

## ③ 売り先の使い分け

- **Proxima Fusion**: Stellaris は水冷鉛リチウム(WCLL系)でブランケットを特許化済み。PbLi は低速循環でありポンプ動力は死活変数ではない → **「MHD 圧損」の看板は刺さらない**。刺さるのは TBR・滞留時間分布(トリチウム回収とインベントリ)・排液性。低速でも強磁場下では浮力駆動 MHD 自然対流が温度・腐食・透過を支配し、ステラレータのねじれ形状での計算例は無い(2本目の論文の弾)
- **Renaissance Fusion**: 自己冷却液体金属が本業 → MHD 圧損計算がど真ん中。**一次ターゲット**
- **Helical Fusion**(東京): 日本在住なら最短距離
- 1本目の論文は Renaissance 型課題(MHD 圧損 Pareto)、Proxima 型課題(低速 PbLi の 3D 挙動)は温存

## ④ alphastell はリスコープ(アーカイブは半分もったいない)

6層マテリアルスタックという製品コンセプトは parastell の縄張りなので捨てる。ただし `core/src/vmec.rs`(NetCDF3 リーダー・フーリエ評価+放射スプライン・**解析 θ/φ 導関数**・オフセット面)は流路生成がそのまま必要とする配管であり、本リポジトリに移植して流用する。「流用できるコードは無い」は事実に反する。

## ⑤ cadrum は無駄どころか基盤層

- `09_bspline`(stellarator-like torus)= vmec.rs の point(i,j) を watertight B-rep にする受け口
- `07_sweep` の ProfileOrient::Auxiliary = ねじれ面追従ダクトの断面姿勢制御
- `08_shell` の halved_shelled_torus = 薄肉ダクト壁
- STEP ソリッド色(#247/#249)= DAGMC/OpenMC の材料タグ要件に直撃
- WASM ブラウザ動作 = 「URL を開けば動く営業マン OSS」

唯一の警告: **カーネル磨きが楽しくて上物を作らないことがリスク**。今後の時間配分は cadrum ≤ 2割(流路生成が実際に要求した機能だけ)、残りを本リポジトリに充てる。
