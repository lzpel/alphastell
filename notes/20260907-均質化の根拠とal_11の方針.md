# 均質化の根拠と al_11 の方針

2026-09-07、al_10 が使っている均質化材料の出所を ParaStell 論文から ARIES-CS まで遡り、al_11（均質化を外す計算）の設計を確定した記録。

## ParaStell は均質化を導出していない

論文中で均質化に触れているのはこの一文だけ。

> The blanket concept used is dual-coolant lithium-lead and the homogenized material definitions used for each component mirror those in ARIES-CS and are given in Table 1 (El-Guebaly et al., 2008).

理由づけも "The reduced detail of low fidelity models accelerates the modeling of design iterations" のみで、**何を均質化したのか（流路・FCI・冷却管）は書かれていない**。Table 1 の体積分率は ARIES-CS の実在する cm スケール 3D 構造をスミアした結果であり、ParaStell の寄与は「層ごとに 1 材料しか置けない」という幾何側の制約の方にある（`invessel_build.py` の構造は下節）。

## Table 1 の各行が表している実構造（ARIES-CS DCLL）

| ParaStell Table 1 | 元の 3D 構造 |
|:--|:--|
| first_wall: He 66 / RAFM 34 | 3.8 cm の F82H 板に He 冷却流路（10 MPa、単一パス、トロイダル交互流で温度を均す）。体積の 2/3 が流路 |
| breeder: LiPb 79 / He 8 / SiC 7 / RAFM 6 | 大型ポロイダルダクトを LiPb が ~10 cm/s で**二パス（往路・復路）**で流れる。各ダクトの内張りが **SiC FCI**（構造機能なし、薄いスリットで圧力バランス、~700 °C の LiPb と FS 界面の共存温度を切り離す熱絶縁）。ダクト間の隔壁が FS/He 冷却管で、構造を持つのはこちら |
| back_wall: RAFM 80 / He 20 | 3 cm の FS 背板と strong back の He 流路 |
| shield: WC 75 / RAFM 15 / He 10 | FS 箱に WC ブロックを充填した永久遮蔽。Δmin を詰めるため B-FS フィラーを WC に置換した ARIES-CS 固有の判断 |
| vacuum_vessel: RAFM 51 / water 49 | 実設計は 2 cm 厚板の不均質構造 |

## ParaStell の幾何が均質化を強制する構造

`/opt/parastell/parastell/invessel_build.py`（`ghcr.io/svalinn/parastell-ci` 同梱）:

- 面は `s=wall_s` の磁束面を、同じトロイダル平面内の法線方向にオフセットしたもの（`Rib.calculate_loci()` :1224、`_normals()` :1203）。θ 方向にスプラインで閉じ（:1255）、φ 方向にロフトする（`Surface.generate_surface()` :1157）
- オフセットは累積スカラー場 `offset_mat(φ,θ)` ひとつ。`populate_surfaces()` :490-508 が radial_build を順に `offset_mat += thickness_matrix` して面を積む
- 1 層 = 外殻 − 内殻 の 1 ソリッド = 材料タグ 1 つ（`generate_components_cadquery()` :526、`RadialBuild` の受け口は `thickness_matrix` と `mat_tag` だけ :1424-1438）
- tet メッシュ側も各層 1 テトラ厚（`InVesselComponentMesh` :1266-1270）

表現できる位相は「同心の閉トーラス殻の列」に固定される。層内のタイリングは原理的に書けないので、書けない構造が体積分率に落ちる。これが均質化の実体。

## ARIES チーム自身が不均質化の効きを測っている

同じ DCLL で ARIES-ACT-2 の中性子計算（[UWFDM-1418](https://fti.neep.wisc.edu/fti.neep.wisc.edu/pdf/fdm1418.pdf)、著者は ParaStell が引く El-Guebaly と同じ）が、裸の増殖ゾーンに構造要素を 1 つずつ足して TBR を記録している。TBR 1.79 → 1.05 の 10 ステップ:

| ステップ | TBR の変化 |
|:--|--:|
| 径方向・ポロイダル被覆の制限 | −10% |
| 2 cm 組立ギャップ | −0.7% |
| 3.8 cm FW (F82H/He) | **−9%** |
| 側壁・背壁・上下壁 | −2.4% |
| **冷却管による分割**（IB 9 本、OB 16 本 / 11.25° ウェッジ、本数は応力解析由来） | **−3.7%** |
| **SiC FCI** | **−3.7%** |
| W 安定化シェル | −3.1% |
| Li-6 濃縮 90 → 40% | −15% |
| 貫通孔 | −2.8% |

本文は「構造壁 + 冷却管 + FCI の合計で −18%」と明言し、"Special care has been taken to model all details to duplicate the exact design specifications" と不均質モデルを明示的に組んでいる。

**この分解の限界**: 「無かった物質を足す」操作なので、組成と配置が同時に変わっている。純粋な「同じ体積分率で均質 vs 不均質」の比較にはなっていない。**その分離が al_11 の空きスロット**。

また ARIES-ACT-2 Table III の実値は OB で LiPb 61.2 / FS 15.4 / SiC FCI 7.1 / He 16.3 vol%。ParaStell が使う 79/8/7/6 はこれより増殖材リッチで、[al_10](../out/al_10_parastell_cad_to_dagmc_example.md) の TBR が論文の 1.10 より高く出た理由の一部はここにもある（形状の違いだけではない）。

## al_11 の主張

**組成を Table 1 に固定したまま、配置だけを不均質にしたときの ΔTBR・Δ発熱分布を出す。** さらにステラレータ固有の変数として、**その誤差が流路方向（ポロイダル / トロイダル / ヘリカル）にどう依存するか**を出す。前者は ARIES の段階的分解が答えていない量、後者は ARIES にそもそも存在しない自由度（トカマクはポロイダル一択）。

## 実装方針: 頂点を共有した同一セル複合体で材料マップだけ差し替える

**同じ点群・同じ三角形・同じ体積分割を使い、材料タグの割り当てだけを変える。** 離散化誤差が両モデルで厳密に相殺するので、差分がそのまま均質化の誤差になる。

1. **径方向の細分は parastell に計算させる**。radial_build を `first_wall` / `fci_front` / `lipb_front` / `wall_mid` / `lipb_return` / `fci_back` / `back_wall` / … に割り、厚み行列の和が元の breeder 厚み行列に一致するようにする。これで層境界面の点群が `invessel_build.Surfaces[name].get_loci()`（:738、形は (層, リブ, 点, 3)）から取れる。ここまでは parastell 無改造
2. **面内の分割は自前**。流路方向 d ∈ `DIRECTIONS`（[20260815](20260815-ブランケット流路構造の調査とDIRECTIONS表現の決定.md) の (n_phi, n_theta)）に対し、面内で d に直交する向きにダクトを並べる。`n × ピッチ = その向きの周長`
3. **セル → DAGMC** は parastell の pydagmc パスと同じ手法（点群 → MOAB 三角形 → volume → material tag、`create_moab_tris_from_verts` :38 と `_generate_volumes_pydagmc` :652）を、細分したセル複合体に対して自前で書く。頂点を共有するので watertight は構成上保証される。CAD ブーリアンも cad_to_dagmc も通らないので、al_10 で数分かかっていた三角形化と imprint の問題が消える
4. **材料マップ 2 種**
   - H: breeder 系セルを全部 al_10 の均質化 `breeder` にする → al_10 の再現（幾何離散化だけが違う対照群）
   - X: セルごとに LiPb / SiC / FS+He を割り当てる。壁厚 t と FCI 厚を、体積和が 79/8/7/6 に一致するよう解く（タイリング恒等式の f がそのまま体積分率）
5. **輸送は al_10 の `run()` をそのまま使う**。同じ四面体線源、同じ FENDL-3.2、同じタリー。materials() に単体 LiPb / SiC / FS+He を足すだけ

`examples/al_11_<name>.py`、出力は `out/al_11_<name>.*`。al_10 と同じく main は 1 本目、定数は全部引数。

### スキャン軸

| 軸 | 値 | 見たいもの |
|:--|:--|:--|
| 配置 | H / X | 均質化の誤差そのもの |
| 流路方向 | poloidal (0,1) / toroidal (1,0) / helical (1,1) | 誤差の方向依存。al_05 の平均 sin² 1.00 / 0.21 / 0.23 と並べる |
| 壁厚 t・FCI 厚 | 数点 | 体積分率を保ったままピッチだけ変える（n は従属変数） |

本数 n は独立変数にしない（[20260815](20260815-ブランケット流路構造の調査とDIRECTIONS表現の決定.md) の結論）。

### 出す量

- ΔTBR（H − X）と統計誤差。ARIES の −3.7%（冷却管）+ −3.7%（FCI）と桁が合うか
- 層別・材料別核加熱の差。特に第一壁直後の勾配とピーク発熱密度
- ストリーミング指標としてマグネットへの核加熱（al_10 では論文の 152 kW と比較不能だったが、H と X の比なら意味を持つ）
- 流路方向ごとの ΔTBR。方向で誤差が変わるなら「均質化した TBR で方向を選ぶと設計判断を誤る」と言える

## リスクと未解決

- **ボリューム数**。61 リブ × 61 点 × 細分をそのままセルにすると 1 周期で 1e4 オーダーの DAGMC volume になり輸送が遅い。セル境界をダクト壁の位置にだけ置き、流れ方向は曲率が必要な分だけに粗くする。落とせなければリブ数を減らす
- **マグネットは CAD のまま**。in-vessel と接しないので混在してよいが、h5m を 2 つ合わせる手順は al_10 と同じ経路になる
- **薄い FCI（数 mm）と 90° 扇形のスケール差**。三角形化の許容差ではなくセル境界そのものなので精度は出るが、細い層のレイトレースコストは要確認
- **s>1 のスプライン外挿**。ParaStell 論文が警告している領域を背面 s=1.08 で使い続けている。法線オフセットへの切り替えは al_11 とは独立の TODO
- H が al_10 を再現しない場合、原因は幾何離散化（ロフト面 vs 三角形面）。まず H と al_10 の体積を突き合わせる
