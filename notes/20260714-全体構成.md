# 全体構成

mhd-tbr-stell の製品定義とレイヤー分業。製品は「wout.nc と流路トポロジーを入れると、ブランケット成立性の判定スカラー3つ(TBR / 総MHD圧損→ポンプ動力比 / 最高壁温)と TBR–圧損 Pareto フロントを分単位で返す判定機」。可視化は副産物。

## レイヤー分業

```
┌──────────────────────────────────────────────────────┐
│ mhd-tbr-stell (本リポジトリ)                          │
│  ├ vmec カーネル: wout.nc 読込・フーリエ評価・        │
│  │   解析 θ/φ 導関数・オフセット面 (alphastell-core   │
│  │   の vmec.rs から移植。6層シェル生成は引き継がない)│
│  ├ 流路生成: 磁気面追従ダクト分割・マニホールド       │
│  ├ 相関式 MHD 圧損ネットワーク (1D ダクト網)          │
│  └ エクスポータ2系統                                  │
│     ├ 材料色付き STEP → DAGMC → OpenMC (TBR)          │
│     └ パラメトリック座標から直接 polyMesh             │
│        (Hartmann 層解像の壁面直交傾斜格子) → epotFoam │
├──────────────────────────────────────────────────────┤
│ cadrum: B-rep カーネル (OCCT 静的リンク・Rust)        │
│   Solid::bspline / sweep / shell / boolean /          │
│   STEP ソリッド色 — 流路の正確な形状とCAD受け渡し     │
├──────────────────────────────────────────────────────┤
│ 外部ソルバー (自作しない):                            │
│   OpenMC(中性子輸送・TBR) / epotFoam(検証用フルMHD)   │
└──────────────────────────────────────────────────────┘
```

設計原則: **ソルバーは書かない**。既存 OSS を配管し、未実施の計算(ステラレータ磁気面上の MHD×TBR 連成)を最初に実行することに新規性を置く。

## 二層速度構成(重要)

- **主力 = 相関式ネットワーク**: Miyazaki/Smolentsev 系の壁伝導度相関で区間ごとの dp/dx、曲がり・拡大・マニホールドは 3D 損失係数。1設計案を秒〜分で判定し、設計スキャンと Pareto 探索を担う
- **フル CFD (epotFoam) は検証の錨**: Ha≈10³ の代表ダクトで相関式との一致(目標: 数%)を示すためだけに使う。実機 Ha≈10⁴ は 10⁸ セル級で非現実的、という査読批判には相関式の Ha スケーリングで回答する
